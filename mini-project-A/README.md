# Mini Project A

## Project Overview
This project presents a comprehensive Exploratory Data Analysis (EDA) of the famous Titanic dataset. The goal is to uncover patterns, demographics, and key factors that influenced passenger survival during the tragedy. The analysis is structured into a Python script generating deep insights and an interactive Streamlit dashboard for easy visualization.

## Objectives
- Conduct a thorough Exploratory Data Analysis (EDA) to understand the dataset's structure and quality.
- Handle missing values and detect outliers.
- Perform feature engineering to extract better predictive features (e.g., FamilySize, Title).
- Visualize distributions and relationships between features and the target variable (`Survived`).
- Build a user-friendly Streamlit dashboard to present key performance indicators (KPIs) and interactive visualizations.

## Dataset
- **Rows:** 891
- **Columns:** 15 (including engineered features)
- **Target Variable:** `Survived` (0 = Died, 1 = Survived)
- **Missing Values:** 
  - `Cabin`: 77.1% missing (Recommended to drop)
  - `Age`: 19.9% missing (Recommended median imputation)
  - `Embarked`: 0.2% missing (Recommended to drop rows or impute mode)

## Exploratory Data Analysis
The analysis pipeline (`EDA.py`) includes the following steps:
- **Dataset Overview:** Extracted shape, datatypes, and memory usage.
- **Missing Value Analysis:** Generated missing percentages and dynamic recommendations for handling them. 
- **Statistical Summary:** Calculated mean, standard deviation, variance, skewness, and kurtosis.
- **Feature Engineering:** Extracted passenger `Title` from names and created `FamilySize` and `IsAlone` flags.
- **Distribution Analysis:** Analyzed numeric features (Age, Fare) using Histograms, KDE plots, and Boxplots.
- **Correlation Analysis:** Generated a correlation matrix and heatmap to identify collinearity.
- **Pairplot & Scatter Matrix:** Visualized multidimensional relationships among key numeric features using Seaborn and Plotly.

## Key Findings
Based on the data-driven analysis generated by the script:
- **Overall survival rate:** Only 38.38% of passengers survived.
- **Female survival rate:** Females survived at an overwhelmingly higher rate (74.2%) compared to males (18.9%).
- **Passenger class observations:** 1st class passengers were prioritized, resulting in the highest survival rate (63.0%), whereas 3rd class had the lowest (24.2%).
- **Age observations:** Children had the highest survival rate (58.0%), while Seniors had the lowest (22.7%).
- **Fare observations:** Fare distribution is highly right-skewed with extreme outliers corresponding to premium first-class tickets (max fare of $512).
- **Embarkation observations:** Passengers embarking from Cherbourg (Port C) had the highest survival rate (55.4%) compared to Queenstown (39.0%) and Southampton (33.7%).
- **Family size observations:** Small families (2-4 members) survived better, with a family size of 4 having the highest survival rate at 72.4%.

## Dashboard Features
The Streamlit app provides an interactive way to explore the data:
- **KPI Cards:** Displaying Total Passengers, Survival Rate, Female Survival Rate, and First Class Survival Rate.
- **Passenger Class Filter:** A sidebar filter that dynamically updates the entire dashboard based on selected class.
- **Interactive Plotly Charts:** Beautiful, hoverable visualizations for Survival by Sex, Survival by Class, and Fare Distribution.
- **Dynamic Metrics:** KPIs adjust instantly to user inputs.
- **Dataset Summary:** A clean breakdown of the dataset properties and EDA highlights.
